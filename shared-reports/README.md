 # Shared Firecrawl reports

 `scripts/firecrawl-social-engagement.cjs` writes timestamped reports to the
 gitignored `reports/` directory and also refreshes stable latest copies here:

 - `latest-social-engagement.json`
 - `latest-social-engagement.md`

 Commit the latest files when you want future Cursor agents to have immediate
 access to the newest Firecrawl engagement analysis.
