# partner-pilot orchestrator discord outreach automation
Partner Pilot Orchestrator is fully armed and operational.

Trigger mechanism:
1. Outreach bot (scripts/partner-outreach-automation.js) sends messages via Playwright to chat widgets (Crisp, Intercom, Olark, Zoho, forms).
2. After sending, it waits ~2 min and scrapes DOM for replies.
3. Replies are classified (positive/negative/unknown) and logged to docs/partner-pilot/responses/outreach-response-log.jsonl.
4. If --auto-trigger flag is passed AND sentiment is positive, it auto-calls partner-pilot-orchestrator.js which:
   - Validates partner in data/partners.json
   - Generates research brief, dev checklist, content specs, analytics tags, PM stories
   - Posts a rich Discord embed update
5. Manual confirm mode: run scripts/confirm-and-trigger-pilot.js to review positives before triggering.
6. Infisical wrapper: scripts/trigger-partner-pilot.sh injects DISCORD_PARTNER_PILOT_WEBHOOK securely.
7. All 5 sub-agent skills are symlinked under ~/.config/goose/skills/.

Discord webhook tested and confirmed delivering embeds successfully.

# partner-pilot twenty-crm discord next-action orchestrator
Partner Pilot Orchestrator updated with Twenty CRM integration and richer Discord embeds.

New components added:
- lib/intent-data/integrations/twenty.js — Node.js Twenty CRM client (create company, person, note, outreachStatus update)
- lib/partner-pilot/recommendNextAction.js — Keyword-based next-action recommendation engine
- scripts/twenty-outreach-sync.js — CLI wrapper for Twenty sync

Orchestrator flow (now 9 phases):
1-2. Validate + activate partner
3-7. Same artifact generation as before
8. Twenty CRM sync — updates company outreachStatus to POSITIVE_INTERESTED, creates note with reply text
9. Discord embed — now includes: company name, actual reply message (truncated), recommended next human action, Twenty CRM link

Discord embed fields:
- 🏢 Company, 🔖 Slug, 📊 Status, 🔗 Attribution, 🎨 Brand Color, 📅 Pilot Start
- 💬 Reply Message (800 char max)
- ✅ Recommended Next Action (from keyword analysis)
- 🗂️ Twenty CRM link or sync status
- 📦 Artifacts list, 🔜 Next Steps

Next-action recommendations mapped from reply keywords:
- call/schedule/meeting → "Schedule kickoff call"
- email/deck/proposal → "Send partnership one-pager + email sequence"
- price/cost/fee → "Send transparent economics memo + pricing call"
- legal/contract/terms → "Share pilot agreement + loop in legal"
- demo/walkthrough → "Book demo / walkthrough call"
- forwarded/right person → "Request intro to decision-maker"
- vague positive → "Follow up within 24 hours"

All scripts syntax-checked and dry-run tested. Discord delivery confirmed.

# partner-pilot twenty-crm opportunity timing-intelligence v2
Partner Pilot Orchestrator v2 — Opportunity-centric Twenty CRM integration.

Core change from v1 (company/person/note model) → v2 (Opportunity on Person):
- Creates Opportunity in Twenty linked to Person (BD contact)
- Opportunity carries: outreach text sent, platform used, optimal timing, reply text, classification, next action
- Timing intelligence: hybrid engine with role-based heuristics, timezone detection, B2B healthcare BD best practices
- Firecrawl enrichment path: scrapes LinkedIn, Twitter/X, job boards for real activity patterns (not yet connected, will use when available)

Modules:
- lib/partner-pilot/timing-intelligence.js — computes optimal time of day, day of week, timezone, platform recommendation
- lib/partner-pilot/twenty-opportunity.js — creates Opportunity, falls back to Note on Person if Opportunity API unavailable
- lib/partner-pilot/recommendNextAction.js — keyword-based next action recommender

Timing algorithm:
1. Load cached research brief (Firecrawl-enriched when available)
2. Infer role from reply text (founder/partnerships/support/marketing)
3. Map role → prime window (BD exec = 8–10am ET Tue–Thu)
4. Detect timezone from HQ city
5. Recommend primary + fallback platform

Orchestrator now accepts --outreach-text to record the exact message we sent.
Discord embed includes: reply text, recommended next action, optimal timing (time/day/TZ/backup), platform.
