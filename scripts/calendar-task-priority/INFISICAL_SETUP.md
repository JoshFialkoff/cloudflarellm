# Infisical Environment Setup — Calendar-Plane Agent

## Where to set secrets

Use the Infisical CLI or dashboard at `secrets.assistedly.ai`.

## Required secrets

| Name | Example | Infisical key suggestion |
|------|---------|--------------------------|
| PLANE_BASE_URL | `http://23.95.189.106` | `plane base url` |
| PLANE_API_KEY | `pl_xxxxxxxxxx` | `plane api key` |
| PLANE_WORKSPACE | `executive` | `plane workspace` |
| PLANE_PROJECT_IDS | `64a3045d...,59048c57...` | `plane project ids` |
| GOOGLE_CALENDAR_ID | `primary` or a calendar ID | `google calendar id` |
| GOOGLE_CREDENTIALS_PATH | `/Users/joshdev/.credentials/gcal_client_secret.json` | `google credentials path` |
| GOOGLE_TOKEN_PATH | `/Users/joshdev/.credentials/gcal_token.json` | `google token path` |

## Optional secrets

| Name | Purpose |
|------|---------|
| DISCORD_CALENDAR_WEBHOOK_URL | Post recommendations to a Discord channel |

## Notes

- `GOOGLE_CREDENTIALS_PATH` should point to the OAuth 2.0 client secrets JSON you downloaded from the Google Cloud Console. **Do not commit this file to git.**
- `GOOGLE_TOKEN_PATH` is auto-generated by the script on first OAuth run and reused thereafter. It contains your refresh token.
- `PLANE_*` variables are shared with `scripts/plane-discord-sync`; you can reuse the same Infisical keys.

## macOS Infisical Agent path

Infisical Agent renders secrets to:
```
/Users/joshdev/.infisical/rendered/.env
```

The `scheduler.py` script automatically falls back to this file if environment variables are not already present.
